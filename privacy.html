Privacy Policy — 7am BTC Uploader

Last updated: October 21, 2026

7am BTC Uploader is a personal software tool owned and operated by one individual, Douglas Brownfield. It is not a public service, is not distributed to anyone, and has exactly one user: its owner.

What the tool does

The tool uploads one video per day to the owner's own YouTube channel, "7am BTC Daily NYC Update," using the YouTube Data API v3 (videos.insert) with the single OAuth scope "youtube.upload."

Data the tool accesses

  • The owner's own Google account authorization (OAuth 2.0) for the youtube.upload scope only.
  • The video files and metadata (title, description, tags) that the owner himself creates each day.

The tool does not read, collect, or store any information about viewers, subscribers, or any other person or channel, and it calls no YouTube API endpoint other than the upload endpoint.

Data stored, and where

The owner's OAuth refresh token and client credentials are stored in a file on the owner's own computer, restricted to owner-only file permissions (0600). Nothing is stored on a server, transmitted to any third party, sold, shared, or used for advertising or analytics.

Revoking access and deleting data

The owner can revoke the tool's access at any time from his Google Account's third-party access settings, and deleting the local token file permanently removes the stored credential. Any stored data is deleted immediately on revocation, and in all cases within 30 days, consistent with the YouTube Developer Policies.

Google and YouTube terms

Google's handling of data is described in the Google Privacy Policy. Use of YouTube is also subject to the YouTube Terms of Service. This tool uses YouTube API Services, and its use is subject to the YouTube API Services Terms of Service.
