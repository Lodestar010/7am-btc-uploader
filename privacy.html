Privacy Policy — 7am BTC Uploader

Effective: October 16, 2026

7am BTC Uploader is a private, single-user application operated by the owner of the "7am BTC Daily NYC Update" YouTube channel. This policy explains what the application accesses and how that access is used.

Who uses this application

Only the owner. The application has no other users, offers no sign-up, and is never operated on anyone else's behalf.

What it accesses

With the owner's authorization, the application uses a single Google permission: uploading videos to the owner's own YouTube channel (the YouTube Data API "youtube.upload" scope). It does not read comments, analytics, subscriptions, or any other account data, and it does not access any other person's Google account or data.

What it stores

The application stores one item: the OAuth token that records the owner's authorization. The token is kept in the owner's secure credential storage and is used only to perform the daily upload. No personal information about any third party is collected, stored, shared, or sold — there is no third-party data involved at any point.

Tracking

None. The application and this site run no analytics, no advertising, and no tracking of any kind.

Revoking access

The owner can revoke the application's access at any time from the Google Account permissions page, which immediately stops it from uploading.
